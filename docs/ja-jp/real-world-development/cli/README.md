**[GitHub Copilot CLI][about-copilot-cli]** を使うと、エージェント型コーディング アシスタントの GitHub Copilot をターミナルで利用できます。コードベースの調査、コードの生成、コマンドの実行、外部ツールとの接続をコマンド ラインから行えるため、グラフィカル エディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys の一連の作業を通して学びます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、プロジェクトを確認します。
2. 星評価の変更を行い、ブラウザーでレビューして、最初のプル リクエスト (PR) を手動でマージします。
3. 絞り込みの issue から始め、Plan モードで方針を決め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、絞り込みの作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーで絞り込みを確認します。
7. 品質保証 (QA) カスタム エージェントを作成し、要件、テスト範囲、検証結果をレビューします。
8. 絞り込みの変更全体をレビューし、Agent Merge を使って絞り込み PR をマージします。
9. コンテキスト、モデル、共有、任意のクラウド委任に役立つスラッシュ コマンドを確認します。

ワークショップでは 2 つの PR を作成します。星評価の PR に続き、指示の更新、スキルの更新、QA プロファイル、テストを含む絞り込みの PR を作成します。絞り込みと品質ワークフローでは、1 つの会話とブランチを使い、各ツールの使い方を学びながら作業を積み重ねます。

## 前提条件

ワークショップに参加する前に、次の準備をしてください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランの GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンド ライン操作の基本的な知識

> [!TIP]
> 有料プランをお持ちでない場合、認定学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コード レビュー、Copilot CLI の機能が含まれます。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用する場合は、管理者が Copilot CLI の使用を有効にしていることを確認してください。
