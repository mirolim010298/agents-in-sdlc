**[El agente de GitHub Copilot en la nube](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** permite que GitHub Copilot trabaje de forma asincrónica en la nube. Asignas el trabajo en GitHub y el agente en la nube lo recoge en segundo plano: explora el repositorio, realiza cambios y abre una solicitud de incorporación de cambios mientras tú tienes libertad para hacer otras tareas.

En estos ejercicios añadirás instrucciones personalizadas que el agente en la nube seguirá y, después, asignarás una incidencia de GitHub y dejarás que implemente el trabajo. Revisarás y utilizarás agentes personalizados para orientar su enfoque, supervisarás y dirigirás sesiones desde el panel de agentes y finalizarás revisando sus solicitudes de incorporación de cambios e iterando sobre los resultados.

## Requisitos previos

Antes de asistir a este taller, asegúrate de contar con lo siguiente:

- [ ] Una cuenta de GitHub con un plan activo **Copilot Student, Pro, Pro+, Business o Enterprise**
- [ ] El agente de GitHub Copilot en la nube habilitado para tu cuenta o organización

> [!TIP]
> ¿No tienes un plan de pago? Las estudiantes y los estudiantes verificadas pueden obtener GitHub Copilot gratis a través de [GitHub Education][callout-student-plan-education]. El plan **Copilot Student** incluye el agente, MCP, la revisión de código y las funciones de Copilot CLI que utiliza este taller, por lo que puedes completar todos los recorridos con él.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> El agente en la nube está disponible en los planes **Copilot Student, Pro, Pro+, Business y Enterprise**, todos excepto Copilot Free. En Copilot Business o Enterprise, un administrador debe habilitarlo para tu organización.

> [!NOTE]
> Este recorrido no incluye MCP. Para explorar el uso de servidores MCP con Copilot, consulta el [recorrido de CLI](../cli/) o el [recorrido de VS Code](../vscode/).
